# Портрет позиции: AI Prompt Engineer без программирования

Дата среза: 24 августа 2026 года.

## География и формат работы

- Санкт-Петербург: принимаются вакансии с удаленным, гибридным и офисным форматом.
- Остальная Россия: принимаются только вакансии с удаленным форматом.
- Если в карточке не указан формат работы, вакансия не считается подтвержденно подходящей до ручной проверки.
- Зарплатный порог задается отдельно для конкретного среза и не меняет требования к навыкам.

## Определение роли

AI Prompt Engineer без программирования - специалист, который превращает бизнес-задачу в понятный сценарий работы с LLM, проектирует промпты, проверяет ответы модели и улучшает результат итерациями.

Это не классический разработчик и не ML-инженер. От специалиста не требуется самостоятельно писать production-код, строить backend, настраивать базы данных или поддерживать инфраструктуру.

## Обязательные навыки

Ниже собраны навыки, которые следует считать обязательными для нашего целевого профиля.

### 1. Prompt engineering

- Проектирование системных и пользовательских промптов.
- Четкая постановка задачи, роли модели, контекста, ограничений и формата ответа.
- Декомпозиция сложной задачи на последовательные шаги.
- Использование примеров и контрпримеров.
- Итеративное улучшение промпта по результату ответа.
- Умение составлять промпты для разных моделей и сценариев.

### 2. Понимание возможностей и ограничений LLM

- Понимание того, как LLM обрабатывает инструкции и контекст.
- Знание причин галлюцинаций, потери контекста и нестабильности ответов.
- Понимание роли системного сообщения, пользовательского запроса и примеров.
- Умение выбирать подходящую модель под сложность и тип задачи.
- Понимание, что ответ модели требует проверки, а не слепого использования.

### 3. Оценка качества результата

- Проверка точности, полноты, релевантности и формата ответа.
- Создание набора типовых примеров для ручной проверки.
- Сравнение версий промпта по заранее заданным критериям.
- Выявление повторяющихся ошибок модели.
- Ведение простой таблицы результатов экспериментов.
- Умение сформулировать критерии хорошего ответа до начала тестирования.

### 4. Фактчекинг и контроль галлюцинаций

- Проверка фактов по надежным источникам.
- Выявление выдуманных ссылок, цитат, имен, цифр и утверждений.
- Настройка инструкций «не выдумывать», указывать неопределенность и задавать уточняющие вопросы.
- Отделение факта от предположения и интерпретации.
- Проверка результата на соответствие исходным данным.

### 5. Работа с контекстом и структурой данных

- Умение подготовить исходные материалы для модели.
- Отбор только релевантного контекста.
- Структурирование текста, таблиц, правил и примеров.
- Понимание ограничений длины контекста.
- Проектирование инструкций для работы с документами и повторяющимися задачами.

### 6. Диалоговый дизайн

- Проектирование понятного сценария общения с пользователем.
- Настройка tone of voice под аудиторию и задачу.
- Обработка неоднозначных запросов и отклонений от сценария.
- Формулирование уточняющих вопросов.
- Подготовка безопасных и полезных отказов.
- Проверка естественности, последовательности и удобства диалога.

### 7. Работа с AI-инструментами без кода

- Уверенная работа хотя бы с одной LLM-платформой.
- Умение использовать ChatGPT, Claude, GigaChat или аналогичные инструменты.
- Работа с шаблонами, проектами, системными инструкциями и сохраненным контекстом.
- Использование no-code интерфейсов для настройки AI-сценариев.
- Умение сравнивать результаты разных моделей.
- Готовность самостоятельно осваивать новые AI-инструменты.

### 8. Аналитическое и продуктовое мышление

- Умение начать с пользовательской или бизнес-задачи, а не с инструмента.
- Понимание целевой аудитории и ожидаемого результата.
- Формулирование полезного результата в измеримых терминах.
- Внимание к деталям и системная проверка результата.
- Умение объяснить, почему выбран именно такой промпт и критерий оценки.

### 9. Коммуникация и документирование

- Грамотный письменный русский язык.
- Умение ясно описывать задачу, ограничения и результат.
- Фиксация рабочих промптов, версий и найденных проблем.
- Подготовка понятных инструкций для команды или заказчика.
- Умение принимать обратную связь и дорабатывать сценарий.

## Не считать обязательными для no-code-профиля

Следующие навыки встречаются в вакансиях, но переводят позицию в продвинутый или программный профиль:

- Python, JavaScript, TypeScript и другие языки программирования.
- Работа с REST API и SDK на уровне разработки интеграций.
- Git и code review.
- Docker, Linux, PostgreSQL, Redis и облачная инфраструктура.
- Backend, frontend, fullstack-разработка.
- ML engineering и обучение моделей.
- Создание production-сервисов и веб-приложений.
- LangChain, LangGraph, CrewAI, AutoGen как инженерные фреймворки.
- Самостоятельная реализация RAG, Tool Calling и multi-agent систем.
- Автоматизированные eval-пайплайны и статистический анализ результатов.

## Продвинутые навыки, но не обязательные

Эти темы полезны после освоения базового профиля:

- Few-shot, zero-shot, ReAct и Self-Reflection.
- Основы RAG и Tool Calling на концептуальном уровне.
- Разработка eval-наборов без программирования.
- Настройка параметров генерации через интерфейс платформы.
- Проектирование голосовых AI-диалогов.
- AI-агенты в no-code конструкторах.
- Prompt injection и базовые методы защиты.
- Работа с изображениями, видео и мультимодальными моделями.

## Итоговый портрет кандидата

Кандидат умеет взять неструктурированную задачу, уточнить цель и аудиторию, подготовить контекст, составить промпт, получить ответ LLM, проверить его на качество и фактические ошибки, затем улучшить сценарий. Он способен документировать рабочее решение и передать его другому человеку.

Кандидат не обязан уметь писать код, но обязан понимать логику задачи, ограничения инструмента и критерии качественного результата. Полная замена мышления генерацией текста не соответствует профилю.

## Правило включения вакансий

В итоговую выборку включаются вакансии, которые одновременно соответствуют двум условиям:

1. В названии или описании есть prompt engineering, vibe coding, AI-креатор, AI-автор, conversational/voice AI designer или близкая формулировка.
2. Вакансия не требует frontend/backend/fullstack-разработки, обязательного языка программирования, ML engineering или сопровождения software-инфраструктуры.

По формату работы применяется географическое правило выше: для Санкт-Петербурга допустимы офис, гибрид и удаленка; для остальных российских регионов только удаленка.

## Минимальный практический экзамен

Кандидат должен уметь без программирования:

1. Превратить расплывчатую задачу в четкое техническое задание для LLM.
2. Написать системную инструкцию и пользовательский промпт.
3. Подготовить три примера хорошего и плохого результата.
4. Проверить пять ответов модели по заранее заданным критериям.
5. Найти галлюцинации и неподтвержденные утверждения.
6. Улучшить промпт после анализа ошибок.
7. Описать ограничения получившегося решения.

## Короткая формула навыков

`Prompt design + LLM literacy + quality evaluation + fact-checking + context design + dialogue design + AI tools + product thinking + communication`

Эта формула определяет обязательный no-code-профиль. Программирование и инженерные интеграции не входят в базовый порог.
