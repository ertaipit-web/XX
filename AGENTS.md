# AGENTS.md

## Принципы работы
- Все изменения делай только в ветке dev.
- Не делай git push, git commit без явного указания пользователя.
- Сохраняй существующий код, не переписывай с нуля без необходимости.
- Сохраняй работоспособность имеющихся тестов и CLI (tools/hh_vacancies.py).
- Не коммить секреты (.env, токены). Используй .env.example как шаблон.

## Цель проекта
Мультиагентная система поиска, анализа, оценки и подготовки отчётов о вакансиях для Go-разработчика.

## Архитектура
- Модуль src/vacancies/: контракты, модели, скоринг, оркестратор, агенты, адаптеры, отчёты.
- Конфиги: config/candidate.yaml, config/scoring.yaml.
- Отчёты: reports/latest.md, reports/latest.json, reports/runs/.
- Документация: docs/architecture.md, docs/agents.md, docs/operations.md.

## Ограничения
- Не подменяй отсутствие данных отрицательным фактом.
- Рейтинг рассчитывается детерминированно.
- Обязательные критерии отделяй от предпочтений.
- Всегда сохраняй ссылку на первоисточник для проверяемых утверждений.
